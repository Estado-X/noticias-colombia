# Temas

Cada tema tiene sus términos de búsqueda. Se combinan con «Colombia» y la fecha de hoy.

| Tema | Términos de búsqueda |
|---|---|
| Política y Congreso | Congreso, Senado, Cámara de Representantes, proyecto de ley, gobierno nacional, partidos |
| Economía y empleo | economía, empleo, desempleo DANE, inflación, tasas Banco de la República, dólar, salario |
| Justicia y derecho | Corte Constitucional, Corte Suprema, Consejo de Estado, Fiscalía, fallo, sentencia |
| Orden público y paz | orden público, conflicto armado, paz, grupos armados, Defensoría del Pueblo, alerta temprana |
| Gobierno y contratación pública | contratación pública, SECOP, Procuraduría, Contraloría, alcaldía, gobernación |
| Ambiente y clima | ambiente, clima, IDEAM, deforestación, lluvias, sequía, El Niño, UNGRD |
| Salud | salud, EPS, Superintendencia de Salud, Ministerio de Salud, hospitales, vacunación |
| Educación | educación, colegios, universidades, ICETEX, ICFES, Ministerio de Educación |
| Tecnología e IA | tecnología, inteligencia artificial, MinTIC, ciberseguridad, startups, conectividad |
| Movilidad y ciudades | movilidad, transporte, metro, vías, tráfico, urbanismo |
| Campo y agro | campo, agro, campesinos, café, Ministerio de Agricultura, precios de alimentos |
| Cultura | cultura, música, cine, libros, festivales, patrimonio |
| Deportes | fútbol, Selección Colombia, Liga BetPlay, ciclismo, deportistas colombianos |
